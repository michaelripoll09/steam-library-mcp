# Security Policy

## Supported Versions

The latest published stable release is supported with security fixes.
Older releases may not receive security fixes.

At the time of writing, the latest published stable release is v2.0.0.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Please use GitHub's private security reporting / Security Advisory flow when
available. If private reporting is unavailable, contact the maintainer
privately rather than publishing sensitive details in a public issue.

When reporting, please include where possible:

- Affected version or commit
- Reproduction steps
- Impact assessment
- Proof of concept, if safe to share
- Suggested remediation, if known

Please redact secrets and API keys from any report or attached material.
